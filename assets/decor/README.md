# SVG Decor Pack

Pack d'éléments de décor 100% SVG pour un jeu mobile tower defense en portrait.

## Contenu
- Forêt : 9 assets
- Canyon : 7 assets
- Marais : 7 assets
- Total : 23 assets SVG

## Guidelines
- Vue top-down / 3-4
- Style cartoon propre et moderne
- Fond transparent
- Pas de contour noir lourd
- Ombres douces
- Lisible entre 64px et 160px
